# UI Automation Project: FinalSurge Negative Testing

## Описание проекта
Проект содержит набор автоматизированных негативных UI-тестов для формы регистрации веб-приложения.
Тесты направлены на проверку корректности работы валидаторов при вводе некорректных данных.

## Технологический стек
* **Язык:** Java 17
* **Фреймворк тестов:** TestNG
* **Библиотека автоматизации:** Selenium WebDriver
* **Архитектура:** Page Object Model (POM)
* **Отчетность:** Allure Reports
* **Сборка:** Maven

## Инструкция по запуску
1. Склонируйте репозиторий: `git clone fs-selenide-negative-Yurchenko`
2. Запустите тесты (все браузеры): bash - mvn clean test
